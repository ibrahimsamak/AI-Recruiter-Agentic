# Resume tailoring

## Rules
- Never invent skills, employers, dates, or metrics.
- Re-order and re-emphasize existing bullets to mirror the job's priorities.
- Mirror the posting's keywords ONLY where the candidate already has the experience.

## Procedure
1. Extract the top ~8 requirements from the job description.
2. For each, find the strongest supporting evidence in the source resume.
3. If no evidence exists, leave it out — do not manufacture it.
4. Run `check_grounding`; fix any unsupported claim before returning.
